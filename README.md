# 🐱 Aventura Gatuna

Un dinámico y divertido juego de plataformas en 2D desarrollado en Python utilizando la librería Pygame. Acompaña a nuestro valiente héroe felino a través de desafiantes niveles llenos de obstáculos, enemigos y plataformas, culminando en un épico combate contra el jefe final.

---

## 🎮 Controles del Juego

* **Movimiento:** Flechas de dirección o teclas **A / D** (Izquierda / Derecha).
* **Salto:** Barra espaciadora o tecla **W**.
* **Atacar:** **Tecla Z** (¡Rasguñar y defenderse de los enemigos!).
* **Pausa:** Tecla **ESC**.

---

## 🚀 Características Principales

* **5 Niveles de Plataformas:** Diseños progresivos con desafíos de salto, obstáculos y enemigos únicos.
* **Combate Dinámico:** Sistema de ataque cuerpo a cuerpo mediante rasguños utilizando la tecla **Z**.
* **Batalla de Jefe Final:** Un enfrentamiento desafiante contra el caniche en el último nivel.
* **Físicas y Cámaras:** Sistema de desplazamiento lateral y físicas personalizadas construidas desde cero.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3
* **Motor Gráfico y Lógica:** Pygame
* **Gestión de Assets:** Sprites, efectos de sonido y niveles estructurados por código
